Отчёт по практической работе №2. Графика в JavaFX

1. Описание приложений и использованных графических элементов

В рамках практической работы были разработаны три приложения, демонстрирующие работу с 2D- и 3D-графикой в JavaFX с использованием Scene Builder и контроллеров.

Задание №1. Простое приложение с графическими элементами

•	Описание. Создано окно с тремя основными фигурами: прямоугольником, кругом и линией. Для каждой фигуры реализованы обработчики событий, позволяющие изменять цвет, размер и положение объектов с помощью мыши.
•	Функции.
o	Изменение цвета круга при нажатии левой/правой кнопки мыши.
o	Изменение цвета прямоугольника при наведении курсора.
o	Вращение линии с помощью мыши.
o	Изменение размера фигур с помощью колёсика мыши.
•	Использованные элементы. Circle, Rectangle, Line, обработчики событий мыши (MouseEvent, ScrollEvent), генерация случайных цветов через класс Random.

Задание №2. Приложение с использованием 2D-графики

•	Описание. Реализовано рисование фигур (линия, круг, прямоугольник) на холсте (AnchorPane) с помощью мыши. Пользователь может выбирать тип фигуры и цвет через элементы управления (SplitMenuButton, MenuItem).
•	Функции.
o	Выбор типа фигуры и цвета для рисования.
o	Начало и завершение рисования фигуры по нажатию и отпусканию мыши.
o	Динамическое изменение толщины линии с помощью Slider.
•	Использованные элементы. AnchorPane, Circle, Line, Rectangle, SplitMenuButton, MenuItem, Slider.

 
Задание №3. Приложение с использованием 3D-графики

•	Описание. На сцене размещён 3D-куб (Box), который можно вращать, перемещать и масштабировать с помощью мыши.
•	Функции.
o	Вращение куба по осям X и Y при перетаскивании мыши.
o	Перемещение куба по оси Z с помощью колёсика мыши.
o	Освещение сцены (AmbientLight, PointLight) для реалистичного отображения 3D-объекта.
•	Использованные элементы. Box, Rotate, Translate, PerspectiveCamera, источники света.

2. Выводы и полученные навыки

В процессе выполнения практической работы были освоены следующие навыки:

•	Работа с графическими примитивами в JavaFX: создание и настройка Circle, Rectangle, Line, Box.
•	Реализация интерактивности: обработка событий мыши (нажатие, перемещение, прокрутка), динамическое изменение свойств объектов (цвет, размер, положение).
•	Использование Scene Builder для визуального проектирования интерфейса и связывания элементов с кодом контроллера.
•	Работа с 2D-графикой: рисование фигур на холсте, управление их свойствами через интерфейс пользователя.
•	Основы 3D-графики в JavaFX: создание и трансформация 3D-объектов, настройка освещения и камеры.
•	Применение объектно-ориентированного подхода для организации кода контроллера, разделения логики обработки событий и управления состоянием объектов.

3. Заключение

В ходе выполнения работы были закреплены теоретические знания по работе с графикой в JavaFX, получены практические навыки создания интерактивных графических приложений как в 2D, так и в 3D. Разработанные приложения демонстрируют основные возможности платформы для визуализации и взаимодействия с графическими объектами, что является важной основой для дальнейшего изучения разработки пользовательских интерфейсов и графических приложений на Java.
